# 📊 CogniLearn AI — Sample Data & Test Fixtures

This directory contains standalone, production-representative sample datasets designed for hackathon evaluators, peer reviewers, and local testing without live camera or database requirements.

## 📁 Included Datasets

| File | Format | Description | Relevant Subsystem |
| :--- | :--- | :--- | :--- |
| [`telemetry_sample.json`](telemetry_sample.json) | JSON Array | 1 Hz telemetry time-series with attention states (`SCREEN_FOCUS`, `NOTE_TAKING`, `COGNITIVE_REFLECTION`, `OFF_TASK`), 6-point EAR, 3D Euler angles (Pitch, Yaw, Roll), and BLE PPG vitals (Heart Rate & HRV RMSSD). | Perception & Wearable Fusion |
| [`cohort_roster_sample.json`](cohort_roster_sample.json) | JSON Object | Complete academic structures for both **School Tier** (Class 10 CBSE `SCH-KV10`) and **College Tier** (B.Tech CSE `COL-CS301`), including student rosters, roll numbers, and baseline focus indices. | Classroom Auto-Tracker & Database |
| [`diagnostic_report_sample.json`](diagnostic_report_sample.json) | JSON Object | Sample diagnostic report generated by Google Gemini 3.0 Flash, strictly constrained by Zod schemas and fed by deterministic TypeScript statistics. | AI Reporting & Observability |

## 🧪 Automated Test Verification

All sample data structures and mathematical models are continuously verified by the automated test suite:

```bash
npm test
```

This executes all 7 test phases defined in `scripts/test_pipeline.ts`:
1. Bounding Box Kalman Filter
2. Hungarian (Kuhn-Munkres) Bipartite Spatial Association
3. 5-Point Umeyama Facial Landmark Procrustes Alignment
4. 512-D L2 Embedding Normalization & Cosine Distance
5. Cognitive Attention State Classifier (Softmax multi-class)
6. DeepSORT-lite Tracking Diagnostics & Identity Locking
7. Multimodal Biometrics & Smartwatch Vitals Fusion (Web Bluetooth GATT `0x180D`/`0x2A37`, HRV RMSSD, and Note-Taking Physiological Validation)
